# Satellite — портфолио

Статический сайт-портфолио: фотография и программирование, русская и английская версии. Файлы сайта находятся в каталоге `dist/`.

## Запуск

Из корня репозитория выполните:

```sh
python -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. Сборка и зависимости не нужны.
