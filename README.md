# Satellite — фото и программирование

Портфолио: [lastie-creative-lab.equaldell131.chatgpt.site](https://lastie-creative-lab.equaldell131.chatgpt.site/)

В репозитории — статические файлы сайта из каталога `dist/`: русская и английская версии, фотогалерея Satellite, страница программирования, интерактивные элементы и изображения.

## Локальный запуск

Из корня репозитория:

```sh
python -m http.server 8000 --directory dist
```

Затем откройте http://localhost:8000.

Сборка и зависимости не требуются.
