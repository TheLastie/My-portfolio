Tonal

A photo palette with contrast checks.

Open the project ↗Source code ↗

Who it is for

Designers who take colours from a photograph and need to know whether they work for an interface.

What it does

Finds the dominant colours, rates contrast against WCAG and shows how they behave in interface roles: text, secondary text, accent and text on accent, in light and dark.

What you get

CSS variables (including interface roles) and a JSON palette.

Limits

Automatic role assignment is a starting point; check the final theme on real screens.
